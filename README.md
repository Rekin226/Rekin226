### Featured project

**[AquaScope](https://github.com/Rekin226/aquascope)** is an open-source Python toolkit that unifies global water data and analysis under one API: twelve collectors (USGS, FAO, GEMStat, EU WFD, and more), Bulletin 17C flood-frequency, FAO-56 evapotranspiration, and an AI methodology recommender.

If it helps your research, you can support the project on [Ko-fi](https://ko-fi.com/getaquascope).
